Ram's Geo Extra — Study Guide

Every supplementary set Coach Ram Iyer has shared for Abhinav, indexed by topic · Last updated Nov 9, 2026

How to use this guide

Ram's extras are not tied to a colour set — they are country studies, skill packs and question banks sent across the season. This guide is the index: what each set contains, what it is for, and where it sits in the prep queue. The files themselves live in the family Gmail (Ram's materials are for Abhinav's private use, so this page lists titles and topics only — nothing of his is reproduced here). Tick a set off when it has been worked through; ticks are saved on this device.

Prep targets: IAC Geography Bee — White set, Nov 22 Canadian Geographic Challenge — school round by Feb 2027 Depth stock for finals

Verify before drilling: Ram notes the newest UK sets were built with AI tools from his own materials, and he invites Abhinav to spot mistakes. Treat scores on those sets as practice, and flag anything that looks off rather than memorising it.

  • United Kingdom practice sets (Nov 9) — the freshest advanced practice; Europe is core White-set territory.
  • Nigeria advanced readings (Nov 6) — the current supplement-trial set; pair with the Nigeria reading-check quiz already in chat.
